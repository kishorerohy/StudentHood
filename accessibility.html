Accessibility

StudentHood is being designed so that as many people as possible can use the website and product comfortably.

Our approach

We aim to support clear keyboard navigation, readable contrast, meaningful text labels, responsive layouts, scalable text and useful alternative text for important imagery.

Ongoing improvement

Accessibility is an ongoing product requirement rather than a one-time check. As StudentHood develops, we will continue testing and improving the experience across devices, browsers and assistive technologies.

Accessibility feedback

If you encounter an accessibility problem, please use the Contact Us page and describe the page, feature or issue you experienced so it can be reviewed.

Standards

We use recognised web accessibility guidance as a design reference. This page does not claim formal certification or conformance until the product has completed appropriate accessibility testing.
